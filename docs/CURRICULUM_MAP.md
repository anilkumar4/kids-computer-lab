# Curriculum Map

## Track A: Little Explorers (UKG)
Target Age: 5-6 | Focus: Identification, pointing, basic interaction.

1. **A1: Meet the Computer** - Identifying computers vs. other objects.
2. **A2: Laptop and Desktop** - Form factors (sorting).
3. **A3: Parts I Can See** - Identifying peripherals (hotspots).
4. **A4: Switch On, Switch Off** - Safely using the power button.
5. **A5: Mouse Fun** - Sandbox for pointing, clicking, and dragging.
6. **A6: Keyboard Fun** - Finding letters on a keyboard.
7. **A7: Safe and Kind** - Rules for sharing and safety (liquids).

## Track B: Tech Champions (Class 4)
Target Age: 9-10 | Focus: How it works, terminology, practical literacy.

1. **B1: What Is a Computer?** - The IPO cycle.
2. **B2: Input & Output Devices** - Classifying peripherals.
3. **B3: Inside the Box** - CPU, RAM, Storage.
4. **B4: Typing Basics** - Home row concepts.
5. **B5: Digital Citizenship** - Passwords and internet safety.
6. **B6: Troubleshooting 101** - Checking cables, rebooting.
