# Content Review & Guidelines

All lessons in the Kids Computer Lab MUST adhere to these guidelines:

1. **Age-Appropriate Language:**
   - **UKG:** Short sentences. Sight words. Direct instructions (e.g., "Tap the star").
   - **Class 4:** Introductory technical vocabulary (e.g., "Processing", "Peripherals").

2. **Multimedia Fallbacks:**
   - Text-to-Speech (TTS) is an *enhancement*, not a requirement.
   - All visual interactives (like Drag and Drop) MUST have tap-to-select and keyboard accessibility alternatives.

3. **Privacy First:**
   - Never prompt a child for real names.
   - Never include external outbound links in the lesson content.
   - Do not use real company names if a generic term exists (e.g., use "Tablet" instead of "iPad").

4. **Tone:**
   - Always positive and encouraging.
   - Incorrect answers in quizzes should say things like "Not quite, try again!" rather than "Wrong."
